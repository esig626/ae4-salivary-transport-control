# Phase 10 machine outputs

These files are regenerated by

```bash
python src/run_identifiability_audit.py
```

- `baseline_printed_equation_audit.json` records direct substitutions into the
  published water, current, acid/base, and transporter equations.
- `stoichiometric_geometry.csv` samples the exact map
  `(J_Ae2,J_Ae4) -> (A,B)=(J_Ae2+J_Ae4,J_Ae2+2 J_Ae4)` on the normalized
  knockout-to-WT square `[0,1]^2`.
- `panel_rank_summary.csv` separates exact algebraic ranks from bounds and
  unavailable physiological panel ranks.
- `run_metadata.json` records the command and SHA-256 checksums.

The results certify structural algebra and discrepancies in the printed
record. They do **not** constitute a reconstructed full-model baseline,
physiological observation Jacobian, or validated secretion prediction.

## Retained affine-fixture files

The same directory also contains files from the separately generated
`identifiability_discrimination` software fixture: `baseline_check.json`,
`derivative_verification.json`, `domain_summary.json`, `panel_metrics.csv`,
`parameter_observations.csv`, and `q_equivalence_set.csv`. These use a declared
affine restoring matrix and proxy `Q_star`; they validate code paths only and
are not salivary-model results. Regenerate them with

```bash
PYTHONPATH=src python -m identifiability_discrimination.run_analysis
```
