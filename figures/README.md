# Figures

Only figures generated from validated project results should be treated as manuscript candidates.

Each final figure should have a reproducibility pointer to the analysis and machine readable result from which it was generated.

`identifiability_stoichiometric_geometry.png` is generated by
`src/run_identifiability_audit.py` from the exact two-transporter aggregate map.
It is a certified flux-coordinate illustration, not a physiological
secretion/state observation surface and not a manuscript candidate under the
current `STOP` decision.

Files under `10_identifiability_discrimination/` belong to the retained affine
software fixture. Their titles label them as non-physiological diagnostics;
they are not manuscript candidates or evidence for a minimal panel.

Files under `12_ae4_mechanism_reconstruction/` are reproducible Task-12 audit
figures. They visualize candidate prediction, closure, transported-cation,
PKA-fold, and resting-capacity comparisons. They are model diagnostics, not
experimental data or manuscript candidates; the local README gives the source
table for each image.
