# Literature

This directory contains the published evidence base for the new project.

The published 2018 AE4 mathematical model should be treated as the primary source for baseline reconstruction.

Future literature work should produce

- `evidence_matrix.csv` with source, experiment, system, perturbation, observable, result, uncertainty, and relevance
- `mechanism_audit.md` separating established AE4 transport properties from hypotheses and model assumptions

The historical unpublished manuscript is not a literature source.
