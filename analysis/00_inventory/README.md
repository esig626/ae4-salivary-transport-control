# Phase 00. Inventory and provenance

## Goal

Establish exactly what exists, what is published, what is historical unpublished material, and what must be independently reconstructed.

## Deliverables

- inventory of historical manuscript, source, figures, and code
- source map from published equations and parameters to the canonical model specification
- list of historical claims that require independent re evaluation
- list of missing information that must be recovered from literature

## Acceptance criterion

Every equation and parameter required for the baseline implementation has a published source or is explicitly labelled as a modelling assumption.
