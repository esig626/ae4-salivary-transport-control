# Phase 02. Knockout reproduction

## Goal

Reproduce the published and historical qualitative distinction between AE2 and AE4 perturbations without yet assigning a mechanism.

## Required analyses

- continuation in AE2 activity
- continuation in AE4 activity
- full knockout limits
- steady state existence and stability checks along the paths
- fluid flow and principal ionic state trajectories

## Acceptance criterion

The independent implementation reproduces the qualitative AE2 versus AE4 phenotype and identifies any discrepancies with the older analysis.
