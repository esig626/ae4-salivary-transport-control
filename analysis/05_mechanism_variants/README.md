# Phase 05. AE4 mechanism variants

## Goal

Compare alternative microscopic descriptions of AE4 cation coupling.

Candidate model classes may include cation independent chloride bicarbonate exchange, sodium coupled exchange, potassium coupled exchange, competitive sodium and potassium coupling with distinct affinities, and other variants justified by current experimental literature.

## Acceptance criterion

Each candidate is thermodynamically and stoichiometrically explicit, calibrated or constrained by published evidence, and compared on common observables.
