# Phase 04. Jacobian and network decomposition

## Goal

Identify the structural pathways through which AE2 and AE4 perturbations reach fluid secretion.

At a regular steady state F(u, theta) = 0, use

du/dtheta = -J^{-1} F_theta

and decompose the resulting output sensitivity into interpretable state and flux contributions.

## Questions

- Which state variables carry AE4 control to fluid flow?
- Is the direct cation balance contribution essential?
- Which compensatory pathways suppress the AE2 phenotype?
- Are the conclusions invariant across a physiological neighbourhood?

## Acceptance criterion

A mechanistic explanation is supported by a reproducible decomposition rather than by parameter magnitude alone.
