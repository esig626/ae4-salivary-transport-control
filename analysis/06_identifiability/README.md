# Phase 06. Identifiability and model discrimination

## Goal

Determine whether whole cell secretion phenotypes can identify AE4 microscopic transport mechanism.

## Required outputs

- structural or practical identifiability assessment where feasible
- profile or likelihood based comparison if data support it
- observables that separate otherwise equivalent mechanisms
- explicit statement of what the knockout phenotype alone can and cannot identify

## Acceptance criterion

The project can distinguish identifiable conclusions from model dependent interpretation.
