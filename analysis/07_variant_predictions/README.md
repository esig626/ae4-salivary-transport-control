# Phase 07. Prospective variant predictions

## Goal

Translate experimentally characterised AE4 changes in sodium and potassium dependence into whole cell predictions.

## Candidate outputs

- predicted secretion rate
- intracellular sodium, potassium, chloride, bicarbonate, and pH responses
- membrane potential changes
- compensatory transporter fluxes
- discriminating experimental measurements

## Acceptance criterion

Predictions are generated from models already validated in earlier phases and are clearly separated from fitted observations.
