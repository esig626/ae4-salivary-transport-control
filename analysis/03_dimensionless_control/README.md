# Phase 03. Dimensionless control analysis

## Goal

Determine whether AE4 has greater control over secretion after removing arbitrary parameter scale.

For an output Q and parameter theta, compare dimensionless coefficients of the form

C_theta^Q = (theta / Q) dQ/dtheta.

## Required analyses

- local control coefficients at the physiological state
- numerical finite difference verification
- implicit differentiation verification
- comparison of raw derivatives and dimensionless coefficients
- control over fluid flow and key ionic observables

## Acceptance criterion

The project can state precisely whether the old AE4 versus AE2 sensitivity contrast survives scale normalization.
