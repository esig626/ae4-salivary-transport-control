\section{Model code and simulation data}
\label{app:code}

The principal model implementation, parameter records, archived simulation data, and Python plotting scripts are available in the reviewer folder of the accompanying repository,
\begin{center}
\url{https://github.com/esig626/ae4-salivary-transport-control/tree/main/reviewer}
\end{center}
The model entry point is \path{model/task52_model.py}, with the underlying cell equations and transport laws in \path{model/frozen_task37/src/modern_full_model/}. These files implement the principal comparison described in \cref{app:model,app:onset}.

The parameter document, \path{PARAMETERS.md}, identifies the parameter definitions, units, and source files. Full precision onset states, prescribed inputs, and numerical settings are provided in \path{parameters/}. The archived trajectories and associated numerical summaries for the three principal combined stimulation cases are in \path{data/central/}. The scripts in \path{scripts/} provide entry points for rerunning these cases, exporting the constructed parameter values, checking file integrity, and plotting the stored numerical results. The original data tables and summary plotting script supplied in \path{ae4_sections.zip} are retained separately under \path{provenance/ae4_sections/}.

The repository README gives installation and execution instructions. \path{SOURCE_MANIFEST.json} records the source revision and identifiers of the copied scientific files. The accompanying reproducibility statement distinguishes complete archived trajectories from reported summaries and specifies the additional source files required for the later compensation analysis. The rounded parameter tables in \cref{app:parameters} are for presentation; the numerical implementation retains the source precision.
