# Extract from the supplied ae4_sections archive

The data files, `plot_recorded_summaries.py`, `SOURCE_NOTES.md` and `source_manifest.json` in this directory are copied from the supplied `ae4_sections.zip`. This README is new and identifies their archival status.

The ZIP predates the current manuscript figure numbering and does not contain the dynamical model implementation or the full later compensation trace. Its older PDF figures, manuscript ledger and bibliography are not duplicated here. Complete principal model files and trajectories are instead collected in the parent reviewer package from the verified repository source objects.

The JSON files recording document and symbolic checks describe the earlier package, not a new verification of the current manuscript. The original script produces two historical summary plots from these CSV tables. It does not reproduce the current Fig_5 compensation curve.
